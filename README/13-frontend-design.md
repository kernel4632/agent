# 前端结构

```text
前端（MDUI，黑白）
        侧边栏
                第一排
                        产品LOGO
                        收起侧边栏按钮（仅在侧边栏张开时显示）
                第二排
                        按钮组
                                主页按钮
                                新建对话按钮
                第三排（仅在侧边栏展开时显示）
                        会话列表（填满高度）
                                会话标题（点击切换到对应会话页面）
                第四排
                        展开按钮（仅在侧边栏收起时显示）
                第五排
                        设置按钮
        界面（填满宽度）
                主页
                        顶部
                                搜索框
                        主体
                                左边
                                        工作区列表
                                                第一排
                                                        工作区
                                                        添加工作区 按钮
                                                第二排
                                                        具体的工作区列表项
                                右边
                                        所选工作区拥有的会话列表
                                                一排下去，按时间归类
                                                        今天
                                                        会话1
                                                        昨天
                                                        会话2
                                                        更早
                                                        会话n
                                                会话
                                                        删除
                                                        重命名
                对话页
                        顶部栏
                                左边
                                        会话标题（双击重命名，失焦或回车确认）
                                右边
                                        上下文统计显示（一个圈，鼠标放上去小窗显示具体的上下文token与占比）
                        对话列表
                                用户消息
                                        消息内容
                                        展示信息（发送时间）
                                        撤回消息按钮（回退并填充输入框）
                                        复制按钮
                                助手消息
                                        纯文本消息（markdown渲染后）
                                        工具展示条
                                                工具标题（易读别名）
                                                回退按钮（点击弹窗确认）
                                                预览内容
                                                操作按钮组（当工具权限为询问时显示）
                                                        拒绝
                                                        允许
                                                        始终允许
                                        请求状态条
                                                文本：API请求
                                                旋转条（请求中显示）
                                                usage展示或tiktoken估算
                                        错误提示条
                        当前任务列表（有则显示）
                        回退后的预览消息和取消回退的按钮（回退后显示，发送消息后隐藏）
                        操作框
                                上传文件按钮
                                输入框
                                切换模型下拉框
                                发送和暂停按钮
                        对话快速跳转地图条（固定右侧）
                                跳转上一个对话按钮
                                每个消息一个小白横条（用户短，助手长，点击跳转）
                                跳转下一个对话按钮
                设置页（离开设置页自动保存）
                        侧边栏+对应的设置项
                                供应商配置
                                        左边
                                                供应商列表
                                                底部是添加供应商按钮
                                        右边
                                                第一排
                                                        供应商名
                                                        供应商启用开关
                                                第二排
                                                        请求地址（API）
                                                第三排
                                                        API Key
                                                第四排
                                                        模型列表
                                                                获取模型列表按钮（点击弹出选择模型窗）
                                                                已添加模型项
                                                                        模型名
                                                                        能力
                                                                        模型设置（点击弹出小窗）
                                                                        模型移除按钮
                                                第五排
                                                        一堆供应商自定义配置
                                工具管理
                                MCP管理
                                系统提示词定义
                                语言与外观
                                数据管理
```
