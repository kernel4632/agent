# 依赖库选型

## 核心框架

| 库        | 用途                              |
| -------- | ------------------------------- |
| `elysia` | HTTP 服务器 + SSE 流式推送             |
| `ai`     | Agent 循环核心：streamText、工具调用、多步推理 |

AI SDK 供应商包全装。

## 工具库

| 库           | 用途                  | 说明                           |
| ----------- | ------------------- | ---------------------------- |
| `zod`       | 参数验证 + 工具 schema 转换 | AI SDK 工具定义必须用 zod，同时用于请求体验证 |
| `unstorage` | 会话持久化               | 统一 KV 存储抽象，替代手动 JSON 文件读写    |
| `nanoid`    | ID 生成               | 会话 ID、工具调用 ID                |
| `defu`      | 配置深合并               | PUT /config 局部更新时的深度合并       |
| `consola`   | 日志                  | 带颜色、级别、scope 的优雅日志输出         |
| `chokidar`  | 文件监听                | 工具目录热重载（新增/修改/删除自动加载）        |
| `tiktoken`  | Token 计数            | 精确估算消息历史 token 量，触发上下文压缩     |
