feat: 会话级 plan/build 模式、自动批准、能力开关

参考 opencode 的 plan / build 切换和 roo code 的 auto-approve，都做成会话级设置，
存在会话目录的 settings.json 里，换台机器打开同一个会话还是同一份。

- mode：plan 只给只读工具（读文件、搜代码、抓网页），build 给全套
- autoApprove：开着就不再弹审批弹窗，但 .agentignore 仍然生效
- capabilities.image / cache / stream：图像、提示词缓存、流式输出，默认全开

plan 模式不是靠提示词实现的：后端把写工具从工具表里摘掉，模型看不到也调不到，
而不是在系统提示词里写"请不要改文件"。这样不依赖模型听话，而且 system 能保持用户
原样——后端不做任何提示词注入，用户没写就是空字符串，默认全原生。

这三项都直接对应 agent-core 的字段名（capabilities / cache / stream），不做二次翻译，
所以界面上看到的开关和真正发给模型的东西是同一件事。

新增接口：
- GET   /session/settings/:sessionId
- PATCH /session/settings/:sessionId
- GET   /session/tools/:sessionId（上一次提交漏了文档，这里补上）

改 mode 会立刻重新装配工具表，所以要求会话没有任务在跑。

新增 tests/settings.test.js，11 条测试盯着这三项真的改变了 Agent 拿到的东西，
而不只是接口返回了什么。
