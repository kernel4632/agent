    API
        /health
            GET
                服务状态、版本号
        /config
            GET
                获取所有配置
            PATCH
                修改配置
        /workspace
            GET
                获取工作区列表及其下属 Session 列表
            POST
                添加工作区
                path
            PATCH
                修改工作区定义
                workspaceId、需要修改的字段
            DELETE
                从工作区列表移除工作区
                workspaceId
                不删除本地目录内容
        /session
            GET
                单个 Session 的全部数据
                sessionId
            POST
                创建 Session
                workspaceId
            PATCH
                修改 Session 配置
                sessionId、需要修改的字段
            DELETE
                删除 Session
                sessionId
            /send
                POST
                    发送用户消息并启动执行
                    sessionId、content
                    返回状态，实时内容通过 Session SSE 接收
            /stop
                POST
                    停止 Session 当前执行
                    sessionId
                    终止该会话的API请求与正在进行的工具和工具等待
            /events
                GET
                    订阅 Session 的 SSE 事件
                    sessionId
                    每个事件需要携带递增的 event id
                    返回文本、推理、工具、审批、任务、usage、上下文和执行状态
            /approval
                POST
                    处理工具权限请求
                    sessionId、toolCallId、decision
                    decision：deny、allow-once、always-allow
            /history
                POST
                    回退工具步骤、回退用户消息或撤销回退
                    sessionId、action、对应目标
                    action：rollback-checkpoint、rollback-message、undo
                    rollback-checkpoint 提供 checkpoint
                    rollback-message 提供 messageId
