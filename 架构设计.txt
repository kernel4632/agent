Agent 最小版本架构设计

当前目标
    先完成一个能够配置模型、管理工作区和会话、流式对话、调用工具及停止执行的本地 Agent。
    审批、回退、usage、上下文统计、任务列表、MCP、skills 和附件后续再增加。


后端技术
    Bun
    Elysia
    server.js 直接注册全部路由，不建立 routes 文件夹
    监听端口 4632

持久化
    config → .agent/config.json
    workspaces → .agent/workspace.json
    session 的 id、status、messages、provider、model → .agent/sessions/{id}.json
    processes、abortController、clients、textOnlyCount 只在内存中使用


server.js
    启动时
        Config.load() 读取 config.json
        Workspace.load() 读取 workspace.json
        直接注册全部 Elysia 路由
        监听 4632
    GET /health
        返回 { status: "ok" }
    GET /config
        返回 Config.get()
    PATCH /config
        返回 Config.update(body)
    GET /workspace
        返回 Workspace.list()
    POST /workspace
        返回 Workspace.add(body.path)
    DELETE /workspace?id={workspaceId}
        返回 Workspace.remove(query.id)
    GET /session?id={sessionId}
        返回 Session.get(query.id)
    POST /session
        返回 Session.create(body.workspaceId, body.provider, body.model)
    PATCH /session
        返回 Session.update(body.id, body.title, body.provider, body.model)
    DELETE /session?id={sessionId}
        返回 Session.remove(query.id)
    GET /session/events?id={sessionId}
        返回 Session.listen(query.id) 的 SSE Stream
    POST /session/send
        返回 Agent.send(body.id, body.content)
    POST /session/stop
        返回 Agent.stop(body.id)


commands/config.js
    Config.load()
        读取 .agent/config.json 到 store.config
    Config.get()
        返回完整 store.config，包括 key 原值
    Config.update(partialConfig)
        将 partialConfig 合并到 store.config
        保存 config.json
        返回完整配置


commands/workspace.js
    Workspace.load()
        读取 workspace.json 到 store.workspaces
    Workspace.list()
        返回全部工作区和会话摘要
    Workspace.add(path)
        创建 { id, path, sessions: [] }
        加入 store.workspaces 并保存
    Workspace.remove(id)
        从 store.workspaces 移除记录并保存
        不删除本地目录和会话文件


commands/session.js
    Session.get(id)
        优先返回 store.sessions 中的会话
        未加载时读取 sessions/{id}.json
        初始化 processes、abortController、clients、textOnlyCount
    Session.create(workspaceId, provider, model)
        创建完整 session
        在工作区 sessions 添加 { id, title: "新对话", lastActiveAt }
        保存 session 和 workspace.json
    Session.update(id, title, provider, model)
        title 修改工作区中的会话摘要
        provider 和 model 修改完整 session
        更新摘要 lastActiveAt 并保存
    Session.remove(id)
        运行中先调用 Agent.stop(id)
        删除 session 文件和 store.sessions 中的会话
        删除工作区中的会话摘要
    Session.save(id)
        只保存 session 的持久化字段
    Session.listen(id)
        建立 SSE Stream
        连接加入 session.clients
        断开时从 clients 移除
    Session.emit(id, event, data)
        向 session.clients 中全部连接发送事件


commands/agent.js
    Agent.send(id, content)
        会话不为空闲时拒绝发送
        创建 user message 并加入 messages
        status 改为 running
        textOnlyCount 归零
        创建 abortController
        保存 session
        异步启动 Agent.run(id)
        返回 { messageId }
    Agent.run(id)
        使用 session.messages 构建模型上下文
        从 store.config.provider 读取 api、key、models
        流式请求 session.model
        将 text、thinking 和 tool_call 按顺序写入 assistant message.content
        通过 Session.emit 发送增量事件
        有工具调用时交给 Tool.runAll，并将 tool_result 写入 tool message
        有工具调用时 textOnlyCount 归零
        没有工具调用时 textOnlyCount 加一
        第一次没有工具调用时继续下一轮
        第二次没有工具调用时为下一轮加入临时工具提醒
        第三次没有工具调用时保留普通回复并退出
        网络超时、限流和 5xx 无限指数退避重试，不限制次数
        正常结束后 status 改为 idle
        不可重试错误时 status 改为 error
    Agent.stop(id)
        abort 当前 abortController
        终止 processes 中全部工具进程
        清空运行时执行状态
        status 改为 idle
        保存 session


commands/tool.js
    Tool.runAll(id, toolCalls)
        同一轮所有工具完全并行执行
        根据 toolName 从 config.tools 列表读取发送给 LLM 的工具信息
        根据 toolName 调用 tools/ 中对应的本地实现
        未在 config.tools 列表中的工具拒绝执行
        每个工具生成 tool_result
        结果保持 toolCalls 原顺序
    Tool.run(id, toolCall)
        启动工具后将进程加入 session.processes
        工具结束后从 processes 移除
        返回 output 和 isError
    Tool.stopAll(id)
        并行终止 session.processes 中全部进程


SSE 事件
    status          { status }
    message         { message }
    text-delta      { messageId, text }
    thinking-delta  { messageId, thinking }
    tool-call       { messageId, toolCall }
    tool-result     { messageId, toolResult }
    error           { message }
