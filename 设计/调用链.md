# 调用链

## 总览

```text
server.js 路由
  → commands
  → store
  → JSON 持久化 / Session.emit SSE
  → HTTP 响应
```

## 配置

```text
GET /config
  → Config.get()
  → store.config

PATCH /config
  → Config.update(body)
  → store.config
  → config.json
```

## 工具加载

```text
应用启动
  → commands/tool.load(server/tools)
  → Tool.scan(server/tools)
  → 扫描并动态导入 *.js
  → store.tools 直接保存 LLM 定义对象
  → Tool 私有索引保存执行函数
```

## 工作区

```text
GET /workspace
  → Workspace.list()
  → Object.values(store.workspaces)

POST /workspace
  → Workspace.add(path)
  → store.workspaces[id]
  → workspace.json

DELETE /workspace?id=...
  → Workspace.remove(id)
  → delete store.workspaces[id]
  → workspace.json
```

## 会话

```text
GET /session?id=...
  → Session.get(id) ?? Session.load(id)
  → store.sessions[id] / sessions/{id}.json

POST /session
  → Session.create(workspaceId, provider, model)
  → store.sessions
  → 工作区 sessions 摘要
  → session 文件 + workspace.json

PATCH /session
  → Session.update(id, title, provider, model)
  → 完整 session / 工作区摘要
  → session 文件 + workspace.json

DELETE /session?id=...
  → Session.remove(id, Agent.stop)
  → 调用传入的 Agent.stop(id)（运行中）
  → 删除完整 session 和工作区摘要
```

## SSE

```text
GET /session/events?id=...
  → Session.listen(id)
  → client 加入 session.clients
  → 返回 SSE Stream
  → 断开时移除 client
```

## Agent

```text
POST /session/send
  → Agent.send(id, content)
  → messages 加入 user message
  → status = running
  → 创建 abortController
  → Session.save(id)
  → Session.emit(message + status)
  → 后台 Agent.run(id)

Agent.run(id)
  → 读取 store.config.provider 的 api 和 key
  → 读取 store.config.prompts 的 system 和 tool
  → 流式请求 model
  → assistant content 直接保存 AI SDK text / reasoning / tool-call
  → Session.emit 增量
  → 有工具调用：commands/tool.run 全部并行
  → AI SDK tool-result 写入 tool message
  → textOnlyCount 控制三次纯文本退出
  → 可重试错误无限退避
  → Agent.finish 保存 idle 或 error 并释放控制器
```

## 工具

```text
commands/tool.run(id, toolCalls)
  → 展开文件和 Shell 自己的 path 参数
  → Tool.execute(name, input)
  → execution 加入 session.tools
  → 未配置或未实现：错误结果
  → 所有调用 Promise.all 并行
  → execution 结束后移出 session.tools
  → 结果按原顺序返回
```

## 停止

```text
POST /session/stop
  → Agent.stop(id)
  → abort abortController
  → session.tools 中的 execution 逐个 abort()
  → 清空运行状态
  → status = idle
  → Session.save + Session.emit(status)
```
