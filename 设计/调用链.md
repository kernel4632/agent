# 调用链

## 总览

```text
server.js 路由
  → commands
  → store
  → JSON 持久化 / Session.emit SSE
  → HTTP 响应
```

## 配置

```text
GET /config
  → Config.get()
  → store.config

PATCH /config
  → Config.update(body)
  → store.config
  → config.json
```

## 工作区

```text
GET /workspace
  → Workspace.list()
  → store.workspaces

POST /workspace
  → Workspace.add(path)
  → store.workspaces
  → workspace.json

DELETE /workspace?id=...
  → Workspace.remove(id)
  → store.workspaces
  → workspace.json
```

## 会话

```text
GET /session?id=...
  → Session.get(id)
  → store.sessions 或 sessions/{id}.json

POST /session
  → Session.create(workspaceId, provider, model)
  → store.sessions
  → 工作区 sessions 摘要
  → session 文件 + workspace.json

PATCH /session
  → Session.update(id, title, provider, model)
  → 完整 session / 工作区摘要
  → session 文件 + workspace.json

DELETE /session?id=...
  → Session.remove(id)
  → Agent.stop(id)（运行中）
  → 删除完整 session 和工作区摘要
```

## SSE

```text
GET /session/events?id=...
  → Session.listen(id)
  → client 加入 session.clients
  → 返回 SSE Stream
  → 断开时移除 client
```

## Agent

```text
POST /session/send
  → Agent.send(id, content)
  → messages 加入 user message
  → status = running
  → 创建 abortController
  → Session.save(id)
  → Session.emit(message + status)
  → 后台 Agent.run(id)

Agent.run(id)
  → 读取 store.config.provider 的 api 和 key
  → 流式请求 model
  → assistant content 增加 text / thinking / tool_call
  → Session.emit 增量
  → 有工具调用：Tool.runAll 全部并行
  → tool_result 写入 tool message
  → textOnlyCount 控制三次纯文本退出
  → 可重试错误无限退避
  → idle 或 error
```

## 工具

```text
Tool.runAll(id, toolCalls)
  → 按 toolName 读取 config.tools 中的工具信息
  → 调用 tools/ 中对应的本地实现
  → 未配置或未实现：错误结果
  → 所有调用 Promise.all 并行
  → processes 记录运行中的子进程
  → 结果按原顺序返回
```

## 停止

```text
POST /session/stop
  → Agent.stop(id)
  → abort abortController
  → 终止 processes
  → 清空运行状态
  → status = idle
  → Session.save + Session.emit(status)
```
