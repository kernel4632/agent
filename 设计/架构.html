Agent Server

四层架构 · 引擎与业务分离 · 工具可热插拔

入口层 唯一的 HTTP 服务入口，只做路由分发，不包含任何业务逻辑
server.js
启动 Elysia 应用，注册全部 REST 路由。每个路由只提取请求参数然后调用对应的 command，自己不做任何数据处理。启动时按顺序加载工具 → 配置 → 工作区 → 会话目录。
GET /health · /config · /workspace · /session · /session/events
POST /session · /session/send · /session/stop · /workspace
PATCH /config · /session   DELETE /workspace · /session
▼
业务指令层 纯业务逻辑：声明式地调用引擎和工具，从 store 读数据、写结果、发 SSE 反馈
agent.js
接收用户消息后，声明式地调用 AgentLoop 引擎。把 store 里的 provider、prompts、tools 传进去，回调里只做三件事：发 SSE、保存 Session、clone 消息。管理 send/stop/finish 生命周期。自己不实现循环逻辑。
session.js
管理会话的完整生命周期：创建、加载、修改、删除、保存。同时负责 SSE 连接——客户端连上时发送 sync 事件同步状态，断开时自动清理。每个会话的保存通过 async-mutex 互斥锁保证串行。
workspace.js
工作区 CRUD。工作区只是 { id, path, sessions[] } 记录，代表用户注册的一个本地项目目录。会话摘要挂在工作区下。删除工作区只移除记录，不碰磁盘目录。
config.js
加载和合并模型供应商配置（api/key/models）与提示词配置（system/tool）。并发修改通过 async-mutex 互斥锁串行，保证不丢字段。
tool.js
工具调度器。启动时扫描 tools/ 目录注册全部工具。运行时把模型的工具调用交给 utils/tool.js 并行执行，收集结果返回给 Agent。模型传什么参数就执行什么，不做任何转换。
▼
数据层 全局内存状态，所有 commands 读写同一份数据。持久化由各 command 自行写磁盘
store.js
单一全局对象，四个字段：config（供应商 + 提示词）、workspaces（工作区 KV，含会话摘要）、sessions（已加载会话的内存缓存，含 messages、状态和运行字段）、tools（LLM 工具定义）。没有封装，直接读写。
▼
基础设施层 封装外部库和协议细节，全部与项目无关，可独立复用。业务层只调用简洁 API
agent.js
纯函数 Agent 循环引擎。接收 messages、provider、tools 等参数，内部完成 Retry→LLM→工具执行→三次纯文本退出。通过回调通知每一步结果，不知道 store 和 SSE 的存在。
llm.js
通过 AI SDK 请求 OpenAI-compatible 模型。流式返回文本、推理和工具调用。内置单轮超时，自动合并 abort 信号。
sse.js
SSE 协议封装：帧编码、广播到多客户端、30 秒心跳保活、连接建立和断开的生命周期管理。
tool.js
扫描工具目录并注册。执行时自动做 signal 检查、流式读取、错误捕获和返回值归一化。工具只需要 export 声明和 execute 函数。
message.js
消息工厂。生成带唯一 ID 的 AI SDK 格式消息：user()、assistant()、tool()、id()。
retry.js
无限重试 + 指数退避（上限 60 秒）。可被 AbortSignal 中断。根据 HTTP 状态码和网络错误码判断是否可重试。
file.js
跨平台原子文件写入。基于 write-file-atomic，写入中途崩溃时旧文件不会损坏。
error.js
从任意 throw 值中安全提取错误消息字符串。消除全项目重复的 instanceof 判断。
▼
工具层 独立可插拔，与项目架构无关。放入文件自动注册，删除文件自动移除。收到什么参数就执行什么
file.js
文件读写列搜。读取内容、覆盖/追加写入、列出目录、按关键词递归搜索文件名。基于 Node.js fs + fdir。
edit.js
精确字符串替换。指定 old 和 new 文本，只改匹配部分。支持 replaceAll。比覆盖整个文件安全。
grep.js
正则内容搜索。基于 ripgrep，返回文件路径、行号和匹配文本。支持文件类型过滤。
glob.js
glob 模式文件查找。支持 ** 递归、* 通配、{a,b} 选择。基于 fast-glob，忽略 node_modules。
shell.js
在指定绝对路径执行系统命令。基于 execa，跨平台 Shell 选择，abort 时杀死整个进程树。
web.js
获取公开网页。支持 text 和 markdown 格式。markdown 模式用 turndown 把 HTML 转成结构化文本。
finish.js
结束当前任务。模型调用此工具发出 stop 信号，Agent 循环收到后正常退出。
数据流向
用户请求
→
server.js
→
commands/agent.js
→
utils/agent.js 引擎
→
Retry + LLM
→
tools/* 执行
→
回调 → SSE
→
浏览器
引擎通过回调把每一步结果交给 commands/agent.js，由它决定保存和广播。用户可随时 stop 中断全链路。
