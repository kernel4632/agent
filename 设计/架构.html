Agent Server

四层架构 · 业务逻辑与基础设施分离 · 工具可热插拔

入口层 唯一的 HTTP 服务入口，只做路由分发，不包含任何业务逻辑
server.js
启动 Elysia 应用，注册全部 REST 路由。每个路由只提取请求参数然后调用对应的 command。
GET /health · /config · /workspace · /session · /session/events
POST /session · /session/send · /session/stop · /workspace
PATCH /config · /session
DELETE /workspace · /session
▼
业务指令层 纯业务逻辑：状态转换、数据持久化、Agent 循环。所有对外能力的实现都在这里
agent.js
接收用户消息后启动 Agent 循环。循环内不断请求 LLM，拿到回复后判断：有工具调用就并行执行全部工具，把结果带回下一轮；纯文本回复连续 3 次就自动结束。用户可以随时 stop 中断整个链路。
session.js
管理会话的完整生命周期：创建、加载、修改、删除、保存。同时负责 SSE 连接管理——客户端连上时发送 sync 事件同步当前状态，断开时自动清理。每个会话的保存操作通过互斥锁保证串行。
workspace.js
工作区的 CRUD。工作区只是一个 { id, path, sessions[] } 记录，代表用户注册的一个本地项目目录。会话摘要存在工作区里。删除工作区不删目录也不删会话文件。
config.js
加载和合并模型供应商配置（api/key/models）和提示词配置（system/tool）。并发修改通过互斥锁串行执行，保证不会丢失字段。
tool.js
工具调度器。启动时扫描 tools/ 目录注册全部工具定义。运行时接收模型的工具调用请求，并行执行全部工具，收集结果返回给 Agent 循环。任一 finish 工具触发结束信号。
▼
数据层 全局内存状态，所有 commands 读写同一份数据。持久化由各 command 自己负责写磁盘
store.js
单一全局对象，包含四个字段：config（供应商和提示词）、workspaces（工作区 KV）、sessions（已加载会话的内存缓存）、tools（LLM 工具定义）。没有 getter/setter，直接读写。
▼
基础设施层 封装外部库和协议细节。业务层只调用简洁 API，不接触编码、信号、重试等底层机制
llm.js
通过 AI SDK 请求 OpenAI-compatible 模型，流式返回文本和工具调用。内置单轮超时和 abort 信号合并。
sse.js
SSE 协议封装：帧编码、广播到多客户端、30 秒心跳保活、连接生命周期管理。
tool.js
扫描工具目录并注册。执行时自动做 signal 检查、流式读取、错误捕获和结果归一化，工具本身只需返回结果。
message.js
消息工厂，生成带唯一 ID 的 AI SDK 格式消息：user()、assistant()、tool()。
retry.js
无限重试 + 指数退避（上限 60 秒）。可中断，支持 onRetry 回调。判断 HTTP 状态码和网络错误码决定是否重试。
file.js
跨平台原子文件写入，基于 write-file-atomic。写入中途崩溃时旧文件不会损坏。
error.js
从任意 throw 值中安全提取错误消息字符串。消除全项目重复的 instanceof 判断。
▼
工具层 独立可插拔工具，与项目架构无关。每个工具只声明参数和 execute 函数，收到什么参数就执行什么
file.js
读取文件内容、覆盖/追加写入、列出目录条目、按文件名关键词递归搜索。基于 Node.js fs + fdir。
edit.js
精确字符串替换。模型指定 old 和 new 文本，只改动匹配的部分而不需要重写整个文件。支持 replaceAll。
grep.js
用正则表达式搜索文件内容。基于 ripgrep，返回文件路径、行号和匹配文本。支持文件类型过滤。
glob.js
用 glob 模式查找文件（**/*.ts 等）。基于 fast-glob，自动忽略 node_modules 和 .git。最多返回 100 个结果。
shell.js
在指定绝对路径执行系统命令。基于 execa，自动跨平台选择 Shell，abort 时杀死整个进程树。
web.js
获取公开网页内容。支持 text 和 markdown 两种格式，markdown 模式用 turndown 把 HTML 转成结构化文本。
finish.js
结束当前任务。模型调用此工具表示任务完成，Agent 循环收到 stop 信号后退出。
数据流向
用户 HTTP 请求
→
server.js 路由
→
agent.js 循环
→
Retry + LLM 请求
→
tool.js 调度
→
tools/* 执行
→
SSE 广播
→
浏览器 EventSource
每一步的结果都通过 SSE 实时推送给前端，用户可以随时 stop 中断任意环节
