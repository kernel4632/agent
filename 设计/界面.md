# 界面设计

本文保留 Agent 的完整界面构想，并明确当前最小版本的实现范围。数据以 [数据.md](数据.md) 为准，接口以 [接口.md](接口.md) 为准。

## 当前范围

当前版本先实现：

- 工作区列表和添加工作区。
- 会话列表、创建、重命名和删除。
- 用户消息、助手文本、思考、工具调用和工具结果。
- 供应商、API、Key、模型和工具允许/拒绝配置。
- 发送消息、流式接收和停止执行。

本文后面标为“后续”的界面保留原设计，但当前后端不提供对应接口。

## 应用布局

应用由左侧边栏和右侧内容区组成。内容区在主页、对话页和设置页之间切换。

### 侧边栏

侧边栏从上到下包含：

1. 产品 LOGO，以及仅在展开状态显示的收起按钮。
2. 主页按钮和新建对话按钮。
3. 仅在展开状态显示的会话列表。点击会话标题进入对应对话页。
4. 仅在收起状态显示的展开按钮。
5. 设置按钮。

## 主页

主页顶部是搜索框，主体分为左右两栏。

### 工作区列表

左栏显示工作区标题、添加工作区按钮和工作区列表。添加按钮打开工作区选择对话框。

### 会话列表

右栏显示当前工作区的会话，按最后活动时间分为“今天”“昨天”“更早”。每个会话支持进入、重命名和删除。

## 对话页

### 顶部栏

左侧显示会话标题。双击进入编辑状态，按回车或失去焦点后确认。

上下文占用圆环属于后续功能。

### 消息列表

用户消息当前显示正文和复制按钮。发送时间和撤回属于后续功能。

助手消息按内容块顺序展示：

- 推理块默认折叠，可以展开。
- 文本块使用 Markdown 渲染。
- 工具调用块显示名称、参数、执行状态和结果。易读别名和回退按钮属于后续功能。
- 工具批准按钮属于后续功能。当前工具根据配置直接允许或拒绝。
- API 请求状态当前只显示请求中或已结束；usage 属于后续功能。
- 执行错误显示在对应轮次中。

任务列表属于后续功能。

回退预览和撤销回退按钮属于后续功能。

### 操作框

操作框当前包含输入框、模型选择器和发送按钮。执行期间发送按钮切换为停止按钮。

附件上传按钮属于后续功能。

### 快速跳转条

快速跳转条固定在对话页右侧，包含：

- 跳转到上一条消息的按钮。
- 每条消息对应一个横条，用户消息较短，助手消息较长。
- 跳转到下一条消息的按钮。

点击横条滚动到对应消息。

## 设置页

设置页左侧是设置导航，右侧是当前设置项。离开设置页时自动保存已修改内容。

### 供应商配置

左侧显示供应商列表和添加供应商按钮。右侧显示：

- API 请求地址。
- API Key。
- 已添加模型列表。
- 模型名称列表的添加和移除。

API Key 按原值读取和写入，不进行脱敏。模型能力、供应商自定义配置和模型发现属于后续功能。

### 其他设置

设置导航还包含：

- 工具管理。
- 语言与外观。
- 数据管理。

MCP、skills、系统提示词、工具易读信息和供应商模型发现属于后续功能。
