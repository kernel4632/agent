# 界面设计

本文描述 Agent 的页面、区域和用户操作，不定义数据字段或接口格式。数据以 [数据.md](数据.md) 为准，接口以 [接口.md](接口.md) 为准。

## 应用布局

应用由左侧边栏和右侧内容区组成。内容区在主页、对话页和设置页之间切换。

### 侧边栏

侧边栏从上到下包含：

1. 产品 LOGO，以及仅在展开状态显示的收起按钮。
2. 主页按钮和新建对话按钮。
3. 仅在展开状态显示的会话列表。点击会话标题进入对应对话页。
4. 仅在收起状态显示的展开按钮。
5. 设置按钮。

## 主页

主页顶部是搜索框，主体分为左右两栏。

### 工作区列表

左栏显示工作区标题、添加工作区按钮和工作区列表。添加按钮打开工作区选择对话框。

### 会话列表

右栏显示当前工作区的会话，按最后活动时间分为“今天”“昨天”“更早”。每个会话支持进入、重命名和删除。

## 对话页

### 顶部栏

左侧显示会话标题。双击进入编辑状态，按回车或失去焦点后确认。

右侧显示上下文占用圆环。悬停后显示 token 数量、模型上下文上限和占比。

### 消息列表

用户消息显示正文、发送时间、撤回按钮和复制按钮。撤回后，原消息内容回填到输入框。

助手消息按内容块顺序展示：

- 推理块默认折叠，可以展开。
- 文本块使用 Markdown 渲染。
- 工具调用块显示易读名称、参数预览、执行状态、结果和回退按钮。
- 需要批准的工具调用块显示拒绝、允许一次、始终允许按钮。
- API 请求状态显示请求中状态以及最终 usage。
- 执行错误显示在对应轮次中。

存在任务时，消息列表下方显示当前任务列表。

执行回退后，操作框上方显示被移除内容的预览和撤销回退按钮。发送新消息后清空这份临时回退内容。

### 操作框

操作框包含上传文件按钮、输入框、模型选择器和发送按钮。执行期间发送按钮切换为停止按钮。

附件上传只保留界面入口，本轮不定义对应的数据结构和接口。

### 快速跳转条

快速跳转条固定在对话页右侧，包含：

- 跳转到上一条消息的按钮。
- 每条消息对应一个横条，用户消息较短，助手消息较长。
- 跳转到下一条消息的按钮。

点击横条滚动到对应消息。

## 设置页

设置页左侧是设置导航，右侧是当前设置项。离开设置页时自动保存已修改内容。

### 供应商配置

左侧显示供应商列表和添加供应商按钮。右侧显示：

- 供应商名称和启用开关。
- API 请求地址。
- API Key。
- 已添加模型列表。
- 获取模型列表按钮和模型选择对话框。
- 单个模型的能力、设置和移除操作。
- 供应商自定义配置。

API Key 按原值读取和写入，不进行脱敏。供应商模型发现接口本轮不定义。

### 其他设置

设置导航还包含：

- 工具管理。
- MCP 管理。
- 系统提示词。
- 语言与外观。
- 数据管理。

MCP、skills、工具清单来源和供应商模型发现能力在后续设计中补充。
