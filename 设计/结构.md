# 后端结构

当前阶段只定义运行最小 Agent 所需的后端文件。前端界面规划保留在 [界面.md](界面.md)，不在本文件中删改或重排。

```text
.agent/
  config.json
  workspace.json
  sessions/

server/
  commands/
    config.js
    workspace.js
    session.js
    agent.js
    tool.js
  tools/
    file.js
    shell.js
    web.js
    agent.js
  utils/
    file.js
    llm.js
    retry.js
    tool.js
  store.js
  server.js
  package.json
  bun.lock
```

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `server.js` | 加载数据，直接注册全部 Elysia 路由，监听 `4632`。不建立 routes 文件夹。 |
| `store.js` | 只定义并导出 config、tools、workspaces 和 sessions 数据结构。 |
| `commands/config.js` | 加载、读取、修改和保存模型及工具配置。 |
| `commands/workspace.js` | 加载、列出、添加和移除工作区。 |
| `commands/session.js` | 创建、读取、修改、删除和保存会话；维护工作区会话摘要和 SSE clients。 |
| `commands/agent.js` | 发送 AI SDK 消息、运行模型循环、保存响应和停止执行。 |
| `commands/tool.js` | 展开工具路径参数，并按会话并行执行和停止工具。 |
| `utils/file.js` | 提供 `File.write(path, content)` 完整文件替换。 |
| `utils/llm.js` | 封装 AI SDK 流式请求、超时和错误字段。 |
| `utils/retry.js` | 提供可被 AbortSignal 中断的无限指数退避等待。 |
| `utils/tool.js` | 提供唯一的 `Tool.scan()` 和 `Tool.execute(name, input, options)` 接口。 |
| `tools/file.js` | 实现文件工具。 |
| `tools/shell.js` | 实现 Shell 工具。 |
| `tools/web.js` | 实现 Web 工具。 |
| `tools/agent.js` | 实现 Agent 工具。 |

`commands/` 正好 5 个文件，按 HOP 规则平铺。每个文件按被操作的业务主体命名，不使用 controller、service、repository 或 handler。
