## 1. 子智能体运行过程可查看

子智能体创建后，目前只能看到主会话里的工具结果，看不到子智能体内部正在执行什么。

- 增加子级页面/子会话视图，可以查看子智能体内部的模型输出、工具调用和工具结果；
- 从子智能体的工具调用处进入，不打断主会话时间线；
- 后续结合下面的层级折叠一起做。

## 2. 助手流改为层级可折叠树

把助手消息里的过程内容从平铺步骤改成树状结构，可逐级展开/折叠：

- 一级：这一轮除最终结束回复之外的全部处理过程；
- 二级：除助手正常说话外的全部工具调用集合，思考也放在这一层；
- 三级：具体工具调用的内容；
- 再往下：工具内部的层级，例如子智能体工具内部又调用工具，继续按层级展开。

折叠行为：

- 默认展开当前正在执行的最下级；
- 某一级完成后自动折叠；
- 整轮全部完成后，直接折叠到一级；
- 展开一级时，下面按完成状态逐级显示。
