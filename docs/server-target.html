重构后：跨目录业务依赖工具只向下 · 不再回指 features
三条向下的线都来自 features/tool.js：它组装 tools/file.js、tools/skill.js、tools/subagent.js。其他工具只依赖 store.js 和 utils/，所以不出现在跨目录图里。

四条规则

  1. 工具只向下。tools/ 可以 import store.js 和 utils/；要会话、审批、保存能力，从运行时 context 拿。
  2. 工具宿主是唯一例外。只有 features/tool.js 组装 tools/ 里的文件、技能和子智能体；其他 feature 不碰工具实现。
  3. 业务单向。commands/ → features/ → tools/；store.js 和 utils/ 是叶子，不 import 上层。
  4. 配置归配置。features/config.js 管读写和迁移；features/approval.js 不再为了保存配置去 import features/agent.js。
