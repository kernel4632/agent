# Goal

`plan.md` 是冻结规格，整个目标期间只读，禁止修改。

## 目标

严格按照 `plan.md` 将项目重构为精简 JavaScript 通用 Agent。

- 全部既定功能必须保留。
- 所有生产代码使用 JavaScript。
- 每个模块实际代码不超过 100 行。
- 每个文件只包含该主体的公开业务方法。
- 不写内部辅助方法、胶水层、补丁分支和重复校验。
- 库能完成的处理全部交给成熟库。
- 业务流程保持线性，理解一个功能最多追踪三个文件。
- 代码包含足够的直白中文注释，让编程小白可以阅读、修改和接手。
- 严禁出现超长单行，复杂表达式必须拆成易读的多行业务步骤。
- 文件必须保留足够多的空行，让不同业务步骤清晰分隔，便于顺序阅读。
- 所有文件结构以及文件内全部方法必须严格按照 `plan.md` 编写，不得增加规格之外的方法、层次或行为。
- 工具和插件保持零注册，放入目录即生效，删除文件即消失。

## 顺序

1. 按照 `plan.md` 重构全部生产代码。
2. 删除旧 TypeScript、类型层、拆分层、隔离运行时和其他计划外代码。
3. 完成第一阶段后提交 Git，并推送到 `kernel4632/agent`。
4. 并行启动多个子智能体扫描全部代码。
5. 子智能体逐项检查：
   - 文件结构与方法签名完全符合 `plan.md`。
   - 全部既定功能存在。
   - 每行代码服务于业务。
   - 没有胶水代码、辅助方法、补丁逻辑、重复校验和自造轮子。
   - 每个模块实际代码不超过 100 行。
   - 命名、注释、依赖方向和零注册符合 HOP。
   - 编程小白可以顺序阅读并修改。
6. 根据审查结果做减法修正。
7. 修正完成后再次提交并推送。
8. 再次并行审查，重复“审查 → 修正 → 提交 → 推送”，直到全部审查通过。
9. 执行完整测试：
   - commands、features、utils、tools、plugins 单元测试。
   - Agent 长循环、并行工具、停止和无限审批测试。
   - 明文持久化、part 级 checkpoint、rollback、undo、fork 测试。
   - 上下文压缩、无限重试、SSE、鉴权和 API 集成测试。
   - 内置、全局、工作区和插件工具测试。
   - MCP、cron、title、websearch 插件测试。
   - 多模态、usage、缓存和模型兼容测试。
   - 启动、关闭、Docker 和实际 HTTP 服务测试。
   - 极端输入、长期执行、中途停止、断线重连和文件恢复测试。
10. 大量调用真实模型完成实战任务，包括多轮工具调用和完整网站编写。
11. 测试阶段发现问题时重新设计并减少代码，不追加补丁层。
12. 测试完成后提交并推送。
13. 最后再次启动多个独立子智能体，对代码、测试结果和 `plan.md` 做最终核对。
14. 只有全部功能、全部测试、全部审查和全部推送均完成，且代码完全符合 `plan.md` 与 HOP，才能完成 Goal。

- 提交作者使用 `AKer4632 <111102931+AKer4632@users.noreply.github.com>`。
