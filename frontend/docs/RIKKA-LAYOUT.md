# RikkaHub 布局改造计划

目标：先把界面改成 RikkaHub 的手机端布局骨架，再只对桌面端明显不自然的地方做自适应。功能、数据、命令层保持现状。

## 参考来源

RikkaHub 是 Kotlin + Jetpack Compose + Material 3 Expressive 的 Android LLM 客户端。

- 手机：`ModalNavigationDrawer`，抽屉默认关闭，由顶部菜单打开。
- 桌面：横向宽度 ≥ 1100dp 时换成 `PermanentNavigationDrawer`，抽屉常驻，顶部不再显示菜单按钮。
- 抽屉：宽 300dp，四周 8dp 内边距；顶部是用户、问候、常用动作、文件夹和会话列表；底部是助手/模型选择和工具入口。
- 会话页：透明顶部应用栏，标题+模型/供应商副标题；消息区；底部输入栏（bottomBar），不是悬浮在内容上的独立卡片。
- 设置：大标题顶部栏 + 返回；内容是按组排列的圆角卡片列表，不是左侧导航栏。
- 颜色：Material You 动态色；大面积使用 `surface` / `surfaceContainer` / `primaryContainer` / `onSurfaceVariant`；圆角较大。
- 图标：Hugeicons。

## 目标结构

```text
App
  ThemeProvider
    .rikka-app
      AppDrawer            手机可关闭抽屉 / 桌面常驻
      .rikka-main
        TopBar             菜单 / 标题 / 副标题 / 页面动作
        main
          DraftView        新对话空状态 + 输入栏
          SessionView      消息区 + 输入栏
          SettingsPage     设置首页 / 设置详情
      CommandPalette
      Toast
```

桌面端：

```text
┌──────────────┬─────────────────────────────────────┐
│ 300px drawer │ TopBar                              │
│ 用户/新建    ├─────────────────────────────────────┤
│ 搜索/工作区  │                                     │
│ 会话列表     │ 消息 / 空状态                       │
│              │                                     │
│ 模型/设置    │ Composer（底部，最大 960px）        │
└──────────────┴─────────────────────────────────────┘
```

手机端：抽屉是覆盖层，主内容始终从左边 0 开始；顶部栏左侧有菜单按钮；输入栏贴底并留安全区。

## 断点

- `>= 1100px` 且横向：抽屉常驻，顶部栏不显示菜单按钮。
- 其他尺寸：抽屉为模态覆盖层，默认关闭；点击菜单打开，点遮罩或选择会话后关闭。
- 输入栏和消息区最大宽度 `--la-chat-width`（960px），小屏自适应。

## 现有数据怎么放

- `workspaces` → 抽屉里的工作区选择器和分组依据。
- 会话摘要的 `updatedAt/createdAt` → 抽屉会话列表的日期分组。
- `store.config.activeModel` → 抽屉底部模型选择。
- 设置页登记表 → 设置首页卡片；详情页继续用现有设置控件。
- 命令面板、Toast、快捷键、会话/设置命令保持不变。

## 视觉规则

- 直接用 Material 3 role token：`--md-sys-color-*`，在 `tokens.scss` 里映射成现有 `--la-*`，不新造一套颜色。
- 抽屉、卡片、输入栏使用 `surfaceContainer*` 和较大圆角；选中会话用 `secondaryContainer` 或 `surfaceContainerHighest`。
- 主按钮、发送按钮使用 `primary` / `onPrimary`；错误使用 `error`。
- 不引入新依赖；继续 Vue + SCSS + 现有 `ui/` 控件。
- 手机和桌面共用同一套 DOM，用 CSS 适配，不做两套页面。

## 阶段

### [ ] R1：外壳、抽屉、顶部栏

- 把全局标题栏/标签条从 App 移除；新增 `app/AppDrawer.vue`、`app/TopBar.vue`。
- 桌面常驻抽屉，手机模态抽屉；菜单按钮只在手机显示。
- 抽屉先放：用户问候、新建/搜索、工作区选择、会话列表（复用现有会话逻辑）、设置入口。
- 新对话页改成 Rikka 式空状态；会话页去掉内部顶部栏。
- 设置页暂时保留现有内容，R2 再改布局。
- 验收：手机/桌面都能打开会话、新建对话、开关抽屉、发送消息；界面检查全过。

### [ ] R2：抽屉和会话页视觉

- 会话列表改成日期分组、胶囊选中态、单行标题+时间/状态。
- 抽屉底部模型选择、设置/帮助入口。
- 会话页顶部标题、模型副标题、文件面板/新对话动作。
- Composer 改成底部输入栏，圆角、建议、工具行按 Rikka 结构排。

### [ ] R3：设置页

- 设置首页改成 Rikka 分组卡片；点击进入详情，详情顶部有返回。
- 保留现有设置字段、保存和测试文案。
- 删除不再使用的旧设置导航。

### [ ] R4：Material You 和桌面修正

- `tokens.scss` 映射 M3 role；圆角、阴影、选中态统一。
- 解决桌面端过宽、空白过多、抽屉过窄/过宽等不自然点。
- 手机 390、桌面 1440、窄桌面 1024 截图检查。
- 更新界面测试；构建、单测、UI、后端测试全过。

## 审查门

每个阶段先看截图和 DOM，再跑完整验证。不为了“像”而牺牲可访问名称和现有行为。
